# qlib Studio — 다운로드 및 설치 안내

**qlib Studio**는 품질공학·통계 분석(관리도, 공정능력, Gage R&R, 회귀, 분산분석, DOE, 비모수, 동등성, 검정력, 다변량, 시계열, 신뢰성, 보조 도구 등)을 지원하는 Windows용 데스크톱 분석 워크벤치입니다.

> 이 저장소는 **실행/설치 파일 배포 전용**입니다. Python이 설치되지 않은 Windows PC에서도 바로 설치해 사용할 수 있습니다.

---

## 다운로드

👉 **[최신 버전 다운로드 (Releases 페이지 이동)](https://github.com/GGHOON/quality-lib-releases/releases/latest)**

| 배포 파일 | 추천 대상 | 실행 방법 |
|---|---|---|
| **`qlibStudio-Setup-0.1.0.exe`** *(추천)* | 일반 Windows PC (ZIP 실행 제한 PC 포함) | 다운로드 후 더블클릭 → 설치 마법사 진행 *(관리자 권한 불필요, 바탕화면·시작메뉴 바로가기 자동 생성)* |
| **`qlibStudio-win64.zip`** | 무설치 포터블 실행 원할 때 | 압축 해제 후 `qlibStudio\qlibStudio.exe` 더블클릭 |

## 처음 실행 시 Windows 보안 경고(SmartScreen)가 뜰 경우

서명되지 않은 신규 배포 파일 실행 시 **"Windows의 PC 보호"** 파란 안내창이 나타날 수 있습니다.
1. 안내창 왼쪽의 **`추가 정보`** 클릭
2. 아래 나타나는 **`실행`** 버튼 클릭

## 주요 기능
- **다중 워크시트**: 엑셀 복사·붙여넣기(`Ctrl+C/V`), `.xlsx` 다중 시트 열기/저장, `.csv` 드래그 앤 드롭, 실행취소(`Ctrl+Z/Y`), 조건부 서식
- **데이터 & 계산**: 필터/분할/쌓기/전치/정렬/순위/코드변경, 수식 계산기(`C1*2+log(C2)`), 표준화, 난수 생성, 확률 분포(PDF/CDF/역CDF)
- **통계분석**:
  - 관리도 7종 (I-MR, Xbar-R, Xbar-S, P, NP, C, U + 특수원인 Test 1–8)
  - 공정능력 분석 (정규, Box-Cox, Weibull, 이항, 포아송), Gage R&R (교차 ANOVA + 6-패널 보고서), 파레토 차트
  - 다중 회귀 분석, 일원 ANOVA + Tukey, 2수준 DOE 분석 & 반응 최적화
  - 기초 검정 (1/2-표본 t, 쌍체 t, Blaker 단일 비율, 두 비율 + Fisher, AD 정규성)
  - 비모수 통계, 카이제곱 교차표, 동등성 검정(TOST), 검정력/표본크기, 상관·PCA·K-Means, 시계열(추세/MA/SES/ACF·PACF), 신뢰성(Weibull/Kaplan-Meier)
- **그래프 19종**: 산점도 행렬, 버블도, 주변 분포도, 점도표, 줄기-잎, ECDF, 구간/개별값 그림, 히트맵, 등고선도, 3D 산점도/표면도 등
- **보조 도구 (마법사)**: 분석 선택 가이드, **사전/사후(Before/After) 공정능력 & 관리도 비교 리포트**, 4-in-1 그래픽 요약 보고서

## 시스템 요구 사항
- Windows 10 / 11 (64-bit)
- Python 별도 설치 불필요
